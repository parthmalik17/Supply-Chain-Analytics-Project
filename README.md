## 📖 Overview

This project analyzes supply chain data using **Quadratic AI** and automates workflows using **n8n**. It helps businesses identify delivery delays, revenue loss, and operational bottlenecks while generating meaningful KPIs for better decision-making.

---

## ✨ Features

- 🤖 AI-powered data analysis
- 📊 Business KPI generation
- ⚙️ Workflow automation with n8n
- 📂 CSV & Excel data processing
- 📈 Revenue and delivery analysis
- 🚚 OTIF, OT & IF performance tracking
- 📦 Customer & product insights
